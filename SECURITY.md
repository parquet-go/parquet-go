# Security

Please do not open a public issue to report a vulnerability. Use GitHub's
private vulnerability reporting instead: the "Report a vulnerability" button
under this repository's Security tab.

https://github.com/parquet-go/parquet-go/security/advisories/new

Fixes land on `main` and ship in the next release. Releases are `v0.x.y` tags
cut from `main`. Only the latest release is supported.

Include the affected version, a reproducer such as a test or a file, and the
impact. Fuzzing findings on untrusted input are welcome.
